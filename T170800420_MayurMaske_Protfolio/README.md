# Mayur Rajabhau Maske — Advanced Interactive Portfolio

A premium multi-page portfolio built with **HTML5, CSS3 and Vanilla JavaScript**. It is designed to satisfy the WebPortfolio Maker academic requirements while also being suitable as a real placement portfolio.

## Pages
- Home
- About
- Projects
- AI Career Advisor case study
- SentinelX case study
- Library Management System case study
- Skills
- Education & Achievements
- Certifications
- Resume
- Contact

## Features
- Responsive multi-page navigation
- Dark/light theme with localStorage
- Scroll reveal animations
- Custom cursor on fine pointers
- Project filtering
- Interactive tilt cards on desktop
- Contact form validation with mailto preparation
- Copy email
- Print/save Resume as PDF
- Semantic HTML5
- CSS Grid/Flexbox
- Reduced-motion support
- SEO metadata
- robots.txt and sitemap.xml
- No fabricated metrics or fake testimonials
- Interactive skills orbit with technology-to-project mapping

## Run locally
Open the folder in VS Code and use Live Server, or serve the folder with any static HTTP server.

## Resume
The `resume.html` page contains a print-ready resume layout. If you want a direct PDF download, place your final PDF at:
`assets/resume/Mayur_Rajabhau_Maske_Resume.pdf`
and add a link to it.

## Deploy
### GitHub Pages
1. Create a GitHub repository.
2. Upload all files.
3. Go to Settings → Pages.
4. Select Deploy from branch → main → root.
5. Open the generated Pages URL.

### Vercel
Import the repository as a static project. No build command is required.

The portfolio includes the required About, Skills, Projects, Resume and Contact/Important Links sections, plus responsive design, CSS styling, JavaScript interactivity, animations/transitions, project filtering, form validation and dark mode.
